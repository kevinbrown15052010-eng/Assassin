Assassin Script - UI

1) Скопируйте папку AssassinScript (в ней logo.png, hands.png и icons/) в Workspace вашего executor.
   Должно получиться: Workspace/AssassinScript/logo.png и т.д.
2) Откройте assassin_script.lua, вставьте код в executor и выполните.

Если каких-то файлов нет, окно всё равно откроется, просто без этих картинок.
